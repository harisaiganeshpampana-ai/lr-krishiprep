# LR KrishiPrep

Agriculture exam mock tests and AI doubt solver, developed by LR AgroSense.

- Website: mock tests for any agriculture exam + AI doubt solver (answers from your study notes)
- Admin page: /admin.html
- Telegram: bot + daily quiz in channel

## Render settings
- Build command: `npm install`
- Start command: `npm start`

## Environment variables
MONGODB_URI, GEMINI_API_KEY, GROQ_API_KEY, ADMIN_PASSWORD, TELEGRAM_BOT_TOKEN, TELEGRAM_CHANNEL_ID, PUBLIC_URL, CRON_KEY
